# calculator
A modern Graphical Calculator
A Graphical Calculator built with Python and Tkinter
GraphCalc is a lightweight, user-friendly desktop application built with Python. Designed to make mathematical operations and function plotting quick and intuitive, it provides a clean interface for both basic calculations and visualizing mathematical functions.

Key Features:
Intuitive UI: A clean, modern layout that removes clutter, allowing you to focus on your math.
Graphical Plotting: Instantly visualize your functions on a dynamic coordinate plane.
Standard Operations: Handles arithmetic, trigonometry, logarithms, and more.
Fast & Portable: Packaged into a single executable file for easy access without the need for complex installations.

Run the .exe file for easy use of the program.
